Hosts & GPUs

Use a dedicated Linux box around the clock, or share your Windows gaming PC without losing frames or RAM.

Shared Windows PC

On Windows 11 with WSL2, boxtray puts a mode switch in the notification area and syncs with boxd inside WSL.

  • Full — Full host budget: boxes receive their full configured CPUs (up to 24), 24 GiB RAM, and GPU access (GPU boxes run in Shared too).
  • Shared — Background builds live within half the host budget (12 GiB total on a PC host) so the desktop stays responsive.
  • My PC — boxtray freezes running CPU boxes immediately via cgroups and runs memory.reclaim to hand RAM back to Windows (measured: 3.2 s to swap cold pages and 3.1 GB returned in 35 s). GPU boxes stop immediately, and boxes still paused past 15 minutes (4 hours once swapped) are stopped and their jobs lost. Switch back earlier to thaw CPU boxes in place.

GPU passthrough

Request a GPU box with --gpu or --size gpu in CLI (or gpu: true / size: "gpu" in box_run; 4 shared / 6 full CPUs, 8 GiB RAM, 40 GiB disk). On WSL2 hosts whose Incus project allows it, box maps /dev/dxg and /usr/lib/wsl into the container so CUDA and PyTorch use your NVIDIA GPU.

Measured on an RTX 3070 WSL2 host: a 4096×4096 PyTorch matrix multiply finishes in 10 ms on the GPU box vs 590 ms on CPU. Only one GPU job runs at a time, so workloads never contend over VRAM.

Queue when busy

Queueing requires a reachable boxd. When the host is in My PC mode or full on memory/CPUs, queued runs wait (CPU runs still launch while an exclusive GPU job is running if CPU and RAM headroom remain, whereas a second GPU job waits in the queue). In MCP box_run, queueing requires an active T3 push context (otherwise busy runs return exit 75; terminal box run waits inline). Pass --no-queue in CLI (or queue: false / push: false in box_run) to skip the queue, and GPU runs requested during My PC always fail at once with exit 75.

boxd holds up to 2 GiB of queued snapshots in all in a crash-safe disk queue and schedules fair-share FIFO by agent session. When push wakeups are active, the local box watch process nudges the agent once after 20 minutes if the job stays queued; boxd expires unstarted entries after 24 hours. Open box ui to reorder or cancel queued runs.

Dedicated Linux server

A cloud VM or home Linux server runs the same provisioning script without Windows modes or tray switches, sizing CPU, memory (3/4 of RAM), and container caps automatically from the hardware. Minimums: Ubuntu or Debian, Linux kernel 6.12+, at least 6 GiB RAM, and 75 GiB free disk for the container pool and /cache.

sudo bash provision/setup-host.sh --build-base

The provisioning guide covers both Ubuntu/Debian servers and the two-step Windows PC installer, plus exact uninstall commands.
