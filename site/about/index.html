agent-box back

// about

Compute on tap, carved out of a gaming PC.

agent-box turns a Windows gaming PC into disposable Linux boxes that coding agents offload heavy work to, without touching Windows.

01

Why it exists

Coding agents on a laptop choke on heavy work: a race-detector test run, a full build, a vitest or Android suite. Meanwhile a gaming PC sits idle most of the day with spare cores going to waste.

agent-box lets agents hand that work to the PC and get the result back, so the laptop stays responsive and the PC earns its keep, without the agent ever touching Windows or waiting on a game.

02

How it works

Incus, running in a WSL2 distro on the PC, provides the boxes, API, auth and web UI. agent-box is the thin glue around it: box, a Go CLI and MCP server agents run on the laptop; boxtray, a Windows tray app that sets how much of the PC agents get; and provision/, the scripts that stand the PC up.

The PC joins the tailnet as its own node, so the laptop reaches it from anywhere behind a real certificate. box run snapshots the worktree, ships it to a box, runs the command on up to 4 CPUs, and returns the exit code and log. Boxes are throwaway compute, never storage; only package caches survive.

03

Games always win

The PC's owner picks one of three modes in the tray: My PC (boxes frozen), Shared (2 CPUs a box) or Full power (4). When a game launches, the tray takes the PC back on its own until the game ends.

The mode is enforced by the tray's admin certificate on every tick, not by an honor system. An agent's certificate can't raise its own limits past what the owner allows, so a running game never loses cores to a box.

04

What it's built on

Incus, WSL2 and Tailscale do the heavy lifting; agent-box writes only the glue, in Go with the standard library first. It runs on the laptop (macOS, Linux or Windows) and the PC (Windows with WSL2). go test ./... runs everything, on Linux and Windows in CI.

The rule behind the project: reuse existing tools and open source before writing code, and keep the custom code thin.

05

Who makes it

Tyler Darisme makes and maintains agent-box, as a-Fig on GitHub. Others contribute through pull requests.

The code is at github.com/a-Fig/agent-box.
