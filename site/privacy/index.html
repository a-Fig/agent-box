// privacy

It runs on your machines. Nothing of ours in the middle.

agent-box is software you install and run, over your own Tailscale network.

01

No server of ours

The laptop talks to the PC directly over your Tailscale network, through Incus's own HTTPS API. Nothing routes through us, and we run no service that your boxes or commands touch.

02

No accounts, no telemetry

There is nothing to sign up for. agent-box collects no analytics and sends us no usage data, no code, no logs and no identifiers. Your worktrees, commands and their output stay between your laptop and your PC.

03

Where your data lives

A box holds your checked-out worktree and whatever a command writes, on the PC's disk, for as long as the box exists. Boxes are disposable: an idle one expires after two hours by default, and deleting a box erases everything but the shared package caches in /cache.

box run refuses environment variables whose names look like secrets (TOKEN, SECRET, KEY, PASSWORD and the like), because boxes are shared and the values would be visible inside the box.

04

This website

This page describes agent-box the software. The website itself is static and sets no cookies. Its host keeps standard server access logs, as any web host does; we don't use them to track visitors.
