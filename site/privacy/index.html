Privacy

As of 2026-11-25

Your code and logs

Worktree snapshots, build outputs, container logs, and pulled artifacts move strictly between your laptop and the host you configured. Nothing goes through a hosted runner or third-party build service.

agent-box sends zero usage analytics or telemetry from box, boxd, or boxtray.

Network and access

Container operations run over your Incus TLS client certificate (generated during host setup, imported once on your laptop with a short-lived trust token) and SSH over your private network or Tailnet.

The host daemon (boxd) binds only to 127.0.0.1:7766. When exposed over HTTPS on your Tailnet via tailscale serve, every request checks the Tailscale-User-Login identity header against your allowlist and requires an explicit capability token for mode changes.

Updates

box can check GitHub Releases for newer versions and verify downloaded archives against SHA256SUMS. To disable automatic update checks, run with AGENT_BOX_NO_UPDATE=1.

This website

Cloudflare hosts agent-box.afig.dev and sees the IP address of each HTTP request. Pages load the Inter typeface from Google Fonts. This website loads no analytics, trackers, or cookies.
