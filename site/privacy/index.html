Privacy

As of 2026-11-25

Your code and logs

Worktree bundles, build outputs, container logs, and pulled artifacts move strictly between your laptop and the host you configured. Nothing goes through a hosted runner or third-party build service.

agent-box sends zero usage analytics or telemetry from box, boxd, or boxtray.

Network and access

Container operations connect to Incus HTTPS on port 8443 using your laptop's Incus client certificate, trusted once with a single-use token generated during host setup.

The host daemon (boxd) listens on 127.0.0.1:7766 by default (configurable via boxd.json) and rejects non-loopback requests. When exposed over HTTPS on your Tailnet via tailscale serve, every request checks the Tailscale-User-Login identity header against your allowlist, and control actions require POST, JSON, and the X-Agent-Box: 1 header.

Updates

box can check GitHub Releases for newer versions and verify downloaded archives against SHA256SUMS. To disable automatic update checks, run with AGENT_BOX_NO_UPDATE=1.

This website

Cloudflare hosts agent-box.afig.dev and sees the IP address of each HTTP request. Pages load Inter and JetBrains Mono from Google Fonts. This website loads no analytics, trackers, or cookies.
