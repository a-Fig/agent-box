Spare compute for your agents,carved out of a gaming PC.

agent-box turns a Windows gaming PC on your tailnet into disposable Linux boxes that coding agents offload heavy work to. One click decides how much of the PC they get, and games always win.

Heavy work leaves the laptop

A coding agent in a laptop worktree hands a build or test suite to a box on the PC, gets the result back, and the box goes away. Nothing is installed on the laptop beyond one small binary.

1

Snapshot and send

box run snapshots the worktree, uncommitted and untracked files included, without touching your git index, and ships it to a box over the tailnet.

2

Run on real cores

The command runs on a Linux box with up to 4 CPUs and 4GiB. A dropped connection loses nothing: reattach with box job.

3

Collect and discard

You get the exit code and log back, and can box pull any output. Throwaway boxes delete themselves; reusable ones keep caches warm.

Three pieces of glue

Incus in a WSL2 distro does the boxes, API, auth and web UI. agent-box is the thin layer around it: a CLI for agents, a tray for the PC's owner, and the scripts that set the PC up.

box

CLI and MCP for agents

One Go binary that syncs a worktree to a box and runs a command there. Every command is also an MCP tool, so agents call it directly: box_run, box_status, box_pull.

boxtray

The PC owner's switch

A Windows tray app. One click picks My PC, Shared or Full power. When a game starts, it takes the PC back on its own, every few seconds, until the game ends.

provision

Set the PC up once

Scripts that stand up the WSL2 distro, Incus, the isolated project and the Tailscale node, so the PC serves boxes on the tailnet behind a real certificate.

The owner decides, games win

The tray writes one mode on the PC. The box CLI only reads it; the tray enforces it every tick with an admin cert agents don't have, so an agent can never take cores a game needs.

My PC

boxes paused

The PC is yours. Boxes freeze, and ones still frozen after 15 minutes are stopped to free RAM. Agents fall back to running locally.

Shared

2 CPUs / box

Agents get a modest slice while you keep working. Paused boxes resume.

Full power

4 CPUs / box

The PC is idle, so agents get the most of it. A launched game instantly pulls it back to My PC until the game quits.

Reuse, don't rebuild.

agent-box is open source, built on Incus, WSL2 and Tailscale, with only the glue written from scratch. Read the design doc to see how each part works and why.
