How it works

Your laptop stages dirty work into a temporary git bundle, syncs it to your Incus box with warm /cache mounts, and returns short digests or built files.

Measured on a 913-test go test -race suite: 420 s on a large box vs 1,013 s on the laptop.

Five tools for your agents

box join installs one stdio MCP server across Claude Code, Codex, and Antigravity (or paste into ~/.cursor/mcp.json).

box_status
Check host mode (Full, Shared, My PC), GPU availability, and free room before starting a heavy build.Returns headroom per size (small, medium, large, gpu) and active jobs.
box_run
Bundle tracked and untracked files (no commits added) and run any command inside the repo's Incus box.Parses failing go test and vitest specs into a 3 KiB digest; after 30 s, background runs wake T3 Code via box watch.
box_job
Wait up to 10 minutes for full job output or page log output without blocking.Optional in T3 Code when push: true handles wakeup automatically.
box_pull
Copy built APKs, binaries, or generated artifacts from a container back into your local worktree.Repo boxes stay up 2 hours idle (unless a waiting launch needs room); throwaway --new boxes stay up to 30 minutes after exit.
box_cancel
Stop a running container command (exit 130) or drop a queued bundle right away.Frees CPU, RAM, and GPU capacity immediately for other sessions.

Hardware you own. Tight by default.

Your repo stays between your laptop and your host — isolated per box, never uploaded to third-party cloud build runners.

Unprivileged Incus boxes

Runs under restricted=true in unprivileged containers (box root maps to an unprivileged host UID) with hard CPU, memory, and disk caps (24 CPUs / 10 boxes on Windows PCs; sized from hardware on Linux servers).

Client-certificate access only

Incus listens on :8443 guarded by restricted TLS client certificates trusted once with a single-use token (plus tailscale serve on a tailnet). boxd binds only to 127.0.0.1:7766.

No git branch churn

box stages dirty edits and untracked files in a temporary index and writes a git bundle — never touching branches or HEAD.

Persistent /cache

Shared caches for Go builds and modules, Gradle, npm, and uv cut cold Android Robolectric tests from 6m 18s to 1m 05s warm.

GPU when requested

--gpu (--size gpu) wires /dev/dxg and WSL CUDA libraries (when allowed by the host project): 4096×4096 PyTorch matmul drops from 590 ms CPU to 10 ms on RTX 3070.

SHA-256 verified installs

install.sh and install.ps1 verify release archives against SHA256SUMS. Set AGENT_BOX_NO_UPDATE=1 to skip update checks.

Setup

Provision your host once, install box on your laptop, and connect your coding agents with box join.

Install on your laptop

curl -fsSL https://raw.githubusercontent.com/a-Fig/agent-box/main/install.sh | sh

Add the host printed during host setup, then wire MCP tools into your installed agents:

incus remote add pc https://<host>:8443 --token <token> && box join

Set up your host

On an Ubuntu or Debian host (Linux kernel 6.12+, at least 6 GiB RAM and 75 GiB free disk):

git clone https://github.com/a-Fig/agent-box && sudo agent-box/provision/setup-host.sh --build-base

Sharing a Windows 11 gaming PC instead? Follow the two-step WSL2 + boxtray guide on Hosts & GPUs.

Questions

Does agent-box create commits or touch my git branches?

No. box run packs your tracked edits and untracked files using a temporary index and a git bundle, then unpacks it inside the box. Your local branches and HEAD stay untouched.

What happens when I want to game on my Windows host?

Click the boxtray icon in the Windows notification area and pick My PC. boxtray freezes CPU boxes via cgroups and runs memory.reclaim to hand RAM back to Windows; GPU boxes stop right away, and CPU boxes still paused past 15 minutes (4 hours in swap) stop too. Switch back earlier to thaw CPU work in place.

Do I need a dedicated GPU server?

No. An Ubuntu or Debian server (kernel 6.12+, 6 GiB RAM, 75 GiB disk) works great for test suites and builds. GPU passthrough (--gpu) is optional on WSL2 NVIDIA hosts.

Why is it faster than starting a Docker container?

/cache volumes hold Go build and module caches, Gradle caches, npm packages, and uv wheels on the host across runs, cutting cold Android tests from 6m 18s to 1m 05s.

How big can the queue get?

boxd stores up to 2 GiB of queued bundles in all in fair-share FIFO order by session and expires unstarted queued jobs after 24 hours. Repo boxes live up to 2 hours idle (unless a waiting launch needs room); throwaway --new boxes stay alive up to 30 minutes after exit for box_pull.

Which agent harnesses work without polling?

T3 Code receives a wakeup pushed by a local box watch process when a background job completes. Claude Code, Codex, Antigravity, and Cursor work via MCP tools (box_run, box_job, box_pull).
