on-demand compute for coding agents

Spare cores from a gaming PC, handed to your agents.

agent-box carves a Windows gaming PC into disposable Linux boxes that coding agents offload heavy work to: test suites, -race runs, builds. You dial how much of the PC they get, and the moment a game starts, the PC is yours again.

// the loop

Heavy work leaves the laptop and comes back done.

A coding agent in a laptop worktree hands a command to a box on the PC and waits for the result. Nothing lands on the laptop but one small binary.

01 / snapshot

Snapshot & send

box run snapshots the worktree, uncommitted and untracked files included, without touching your git index, and ships it to a box over Tailscale.

02 / run

Run on real cores

The command runs on a Linux box with up to 4 CPUs and 4GiB. Drop the connection and nothing is lost: reattach with box job.

03 / collect

Collect & discard

You get the exit code and log, and box pull any output. Throwaway boxes delete themselves; named boxes keep caches warm.

// the build

Three thin pieces over Incus.

Incus in a WSL2 distro does the boxes, API, auth and web UI. agent-box writes only the glue around it.

box

CLI & MCP for agents

One Go binary that syncs a worktree to a box and runs there. Every command is also an MCP tool, so agents call it directly: box_run, box_status, box_pull.

boxtray

The owner's throttle

A Windows tray app. One click sets My PC, Shared or Full power. When a game starts it reclaims the PC on its own, every few seconds, until the game quits.

provision

Stand the PC up

Scripts that build the WSL2 distro, Incus, the isolated project and the Tailscale node, so the PC serves boxes on the tailnet behind a real certificate.

// games win

You decide how much. The PC enforces it.

The tray writes one mode; the box CLI only reads it. The tray re-applies the mode every tick with an admin certificate agents don't have, so an agent can never grab cores a game needs.

My PC
boxes frozen

The PC is yours. Boxes pause; ones still frozen after 15 minutes stop to free RAM. Agents fall back to running locally (exit 75).

Shared
2 CPUs / box

Agents get a modest slice while you keep working. Paused boxes resume.

Full power
4 CPUs / box

The PC is idle, so agents get the most of it. Launch a game and it snaps back to My PC until the game quits.

// reuse, don't rebuild

Open source, built on tools that already work.

Incus, WSL2 and Tailscale do the heavy lifting. agent-box is the glue, in Go, standard library first. Read the design doc for how each part works and why.
