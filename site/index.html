Works where your agents run

Install box on your laptop and connect one Linux or Windows WSL2 host. Your coding agents call MCP tools; you keep quiet fans.

In T3 Code, background runs end the turn right away and push results straight back to the thread — zero polling loops. box join · push wakeups

How it works

Your laptop snapshots uncommitted changes into an Incus box on your host, builds against persistent /cache volumes, and returns failure digests or artifacts.

Measured on Murmur's go test -race suite (913 tests): 420 s on a large box vs 1,013 s on the laptop.

Five tools for your agents

box join registers one MCP server across Claude Code, Codex, and Antigravity (or paste into ~/.cursor/mcp.json). Every tool uses the same rules as the CLI.

box_status
Check host mode (Full, Shared, My PC), GPU availability, and free slots before starting a heavy build.Returns headroom per size (small, medium, large, gpu) and queue depth.
box_run
Snapshot tracked and untracked files (no throwaway commits) into an isolated container and run any shell command.Parses test runners into short failure digests on error instead of dumping 20,000 log lines.
box_job
Check elapsed time, queue position, or live tail lines for a background run by job ID.Optional on T3 Code, where finished runs push directly to the waiting thread.
box_pull
Copy built APKs, compiled binaries, or generated files from a box back into your local working tree.Works up to 30 minutes after a throwaway --new run ends.
box_cancel
Stop a running container or remove a queued snapshot immediately when requirements change.Frees host CPU, RAM, and GPU lock right away for other sessions.

Hardware you own. Tight by default.

Your repo stays between your laptop and your host — isolated per run, never uploaded to third-party cloud build runners.

Unprivileged Incus boxes

Runs under restricted=true as a non-root container user with hard CPU, memory, and disk limits (24 CPUs, 10 containers cap).

Private network only

Control traffic runs over Incus TLS client certs and Tailscale SSH. boxd binds only to 127.0.0.1:7766 behind tailscale serve.

No git branch churn

Snapshots tar dirty tracked and untracked files straight to the box. Nothing pushes temporary commits or alters your branches.

Persistent /cache

Host caches for Go, Cargo, Gradle, npm, and uv cut Android Robolectric tests from 6m 18s cold to 1m 05s warm.

GPU when requested

-s gpu wires /dev/dxg and WSL CUDA libraries: 4096×4096 PyTorch matmul drops from 590 ms CPU to 10 ms on RTX 3070.

SHA-256 verified installs

install.sh and install.ps1 check release tarballs against SHA256SUMS. Set AGENT_BOX_NO_UPDATE=1 to skip update checks.

Setup

Provision your host once, install box on your laptop, and connect your coding agents with box join.

Give to your agent

Paste this prompt into Claude Code, Codex, Antigravity, or T3 Code. Your agent reads /setup directly and asks before running commands.

Read /setup markdown

Install on your laptop

curl -fsSL https://raw.githubusercontent.com/a-Fig/agent-box/main/install.sh | sh

Add the host printed during host setup, then wire MCP tools into your installed agents:

incus remote add pc https://<host>:8443 --token <token> && box join

Set up your host

On an Ubuntu or Debian host (Linux kernel 6.12+, at least 6 GiB RAM and 75 GiB free disk):

git clone https://github.com/a-Fig/agent-box && sudo agent-box/provision/setup-host.sh --build-base

Sharing a Windows 11 gaming PC instead? Follow the two-step WSL2 + boxtray guide on Hosts & GPUs.

Questions

Does agent-box create commits or touch my git branches?

No. box run packs your tracked edits and untracked files into a snapshot and unpacks it directly inside the box. Your local branches and history stay untouched.

What happens when I want to game on my Windows host?

Click the boxtray icon in the Windows notification area and pick My PC. Active containers freeze cleanly via cgroups and memory.reclaim returns RAM to Windows, then resumes everything when you switch back.

Do I need a dedicated GPU server?

No. A cheap Ubuntu or Debian server (kernel 6.12+, 6 GiB RAM, 75 GiB disk) works great for test suites and builds. GPU passthrough (-s gpu) is optional on WSL2 NVIDIA hosts.

Why is it faster than starting a Docker container?

/cache volumes hold Go build and module caches, Cargo crates, Gradle caches, npm packages, and uv wheels on the host across runs, cutting cold Android tests from 6m 18s to 1m 05s.

How big can a snapshot or queue get?

boxd persists snapshots up to 2 GiB per job in fair-share FIFO order by session and expires unstarted queued jobs after 24 hours. Throwaway boxes stay alive up to 30 minutes for box_pull.

Which agent harnesses work without polling?

T3 Code receives a direct push wakeup when a background job completes. Claude Code, Codex, Antigravity, and Cursor work via MCP tools (box_run, box_job, box_pull).
