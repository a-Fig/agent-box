Project Fano GitHub

Linux boxes for your agents,on your own computer.

Keep heavy tests and builds off your laptop. Send them to a spare Linux server or your gaming PC, and take the PC back whenever you want it.

View on GitHub Still early

What it does

Project Fano spins up throwaway Linux boxes on your other machine, using Incus. Big test suites and builds happen there instead of bogging down your laptop.

How it works

Agents use the box CLI or MCP tool to copy your working tree to a box, run a command, and get the output back. On Windows, a tray icon lets you switch between My PC, Shared, and Full.

Why Fano

Named after Robert Fano, who started MIT's Project MAC in 1963 and helped invent time-sharing: the idea that one computer can be shared like a utility.

Where it's at

Right now it's built around one person's daily setup and isn't ready for outside use yet. The code and notes are public at github.com/a-Fig/agent-box.
