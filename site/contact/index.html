Contact

agent-box is maintained by a-Fig on GitHub.

Bugs, features, and questions

Open an issue at github.com/a-Fig/agent-box/issues. For a bug, include what you ran, what you expected, what happened, your laptop OS, and your host OS (Ubuntu/Debian or Windows WSL2).

Issues are public, so leave out private hostnames, tailnet names, IP addresses, or secrets.

Code changes

Pull requests target dev. Open github.com/a-Fig/agent-box/pulls, describe why and how you verified the change, and leave out private hostnames, tailnet names, IP addresses, or secrets.

A security problem

agent-box has no private security reporting address listed yet. Open an issue saying you found a security problem and which part of agent-box it affects, without exploit details, and ask the maintainer for a private way to send the rest.
