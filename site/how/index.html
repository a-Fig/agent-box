How a remote run works

Your coding agent starts a heavy test or build locally; agent-box ships the snapshot to your own host and wakes the thread when it finishes. Scroll to trace one job.

01 · Snapshot

Tracks dirty edits without committing

When your agent calls box_run, box tars tracked modifications and untracked files — never adding throwaway commits — over Incus TLS or Tailscale SSH.

02 · Incus + /cache

Fresh container, warm build cache

The host creates an isolated Incus container (non-root, capped CPUs and RAM) and mounts shared /cache folders so Go, Cargo, Gradle, and npm stay warm.

03 · Fair-share queue

Queues safely when the host is full

When slots fill up, a GPU job holds the RTX card, or your PC is in My PC mode, boxd stores snapshots (up to 2 GiB) in fair-share FIFO order.

04 · Shared PC mode

Freezes and gives back RAM when you game

Flip the Windows tray icon to My PC and boxd freezes running boxes cleanly with cgroups and runs memory.reclaim (about 35 s to settle), resuming when you switch back.

05 · Failure digest

Cuts noisy logs to what failed

Instead of flooding agent context with 20,000 log lines, box extracts failing specs from Go, pytest, Jest/Vitest, Cargo, and Gradle — plus where the full log lives.

06 · Push wakeup

Zero polling; laptop stays free

In T3 Code, background runs return right away so your agent thread ends its turn. When exit status arrives, boxd pushes the result straight back to that thread.

07 · Pull & cleanup

Fetch artifacts back, leave containers behind

Call box_pull to copy APKs, wheels, or built binaries back into your worktree. Throwaway boxes stay warm up to 30 min for pulls while /cache persists across runs.

How a remote run works

Your coding agent starts a heavy test or build locally; agent-box ships the snapshot to your own host and wakes the thread when it finishes.

01 · Snapshot without committing

When an agent calls box_run, box tars modified and untracked files from your working tree without mutating git history.

02 · Isolated Incus box with warm /cache

Every run starts a fresh unprivileged container with persistent /cache volumes mapped for Go, Cargo, Gradle, and Node.

03 · Crash-safe fair-share queue

If capacity is full or an exclusive gpu box is busy, boxd persists snapshots up to 2 GiB and dispatches fair-share FIFO by session.

04 · Windows My PC freeze & RAM reclaim

Switching the Windows tray to My PC freezes active cgroups without killing builds and calls memory.reclaim to hand gigabytes back to Windows.

05 · Structured failure digests

box summarizes test failures for Go, pytest, Jest, Vitest, Cargo, and Gradle so agents read the error, not 20,000 passing lines.

06 · Push notification when done

T3 Code runs return immediately with async: true; boxd pushes completion straight back into the conversation thread.

07 · Pull artifacts & keep /cache

box_pull copies binaries, wheels, or APKs back to the laptop worktree within the 30 min throwaway window while /cache stays warm.
