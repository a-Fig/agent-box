How a remote run works

Your coding agent starts a heavy test or build locally; agent-box ships the bundle to your own host and wakes the thread when it finishes. Scroll to trace one job.

01 · Bundle

Tracks dirty edits without committing

When your agent calls box_run, box stages tracked edits and untracked files in a temporary index and writes a git bundle — never touching branches or HEAD — over Incus HTTPS TLS.

02 · Incus + /cache

Isolated box, warm build cache

Each repo reuses its own unprivileged Incus box for up to 2 h idle (or pass new: true for a 30 min throwaway) with shared /cache volumes for Go, Gradle, npm, and uv.

03 · Fair-share queue

Queues safely when the host is busy

With boxd reachable and a T3 push context (or terminal box run), busy runs buffer in up to 2 GiB of queued bundles in all (fair-share FIFO, box watch nudge at 20 min, 24 h TTL). A second --gpu job waits on the GPU while CPU runs start if room remains; GPU runs during My PC exit 75.

04 · Shared PC mode

Freezes and gives back RAM when you game

Flip the tray icon to My PC and boxtray freezes CPU boxes with cgroups and runs memory.reclaim (3.2 s to swap; 3.1 GB back in 35 s). GPU boxes stop immediately; CPU boxes still paused past 15 min (4 h swapped) stop.

05 · Failure digest

Cuts noisy logs to what failed

Instead of flooding agent context with 20,000 log lines, box extracts failing specs from go test and vitest runs into a 3 KiB digest — plus where the full log lives.

06 · Push wakeup

Zero polling; laptop stays free

In T3 Code, if a run takes over 30 s, box_run returns a job ID so your thread ends its turn. A lightweight local box watch process pushes completion via t3 thread send.

07 · Pull & cleanup

Fetch artifacts back, leave containers behind

Call box_pull to copy APKs, wheels, or built binaries back into your worktree. Throwaway boxes stay alive up to 30 min after exit while /cache stays warm.

How a remote run works

Your coding agent starts a heavy test or build locally; agent-box ships the bundle to your own host and wakes the thread when it finishes.

01 · Bundle without committing

When an agent calls box_run, box packs modified and untracked files as a git bundle from a temporary index without mutating git branches or HEAD.

02 · Isolated Incus box with warm /cache

Each repo reuses its own unprivileged container (2 h idle TTL, or pass new: true for a throwaway) with persistent /cache mounts for Go, Gradle, npm, and uv.

03 · Crash-safe fair-share queue

With boxd reachable and a push context (or terminal box run), busy runs buffer up to 2 GiB in all and dispatch fair-share FIFO by session (CPU runs still launch while GPU is busy if capacity remains; GPU runs during My PC exit 75).

04 · Windows My PC freeze & RAM reclaim

Switching the tray to My PC makes boxtray freeze active CPU cgroups and run memory.reclaim (3.1 GB back in 35 s). GPU boxes stop at once; CPU boxes paused past 15 min (4 h swapped) stop.

05 · Structured failure digests

box summarizes failing specs from go test and vitest within a 3 KiB budget so agents read failures instead of 20,000 passing lines.

06 · Push notification when done

Runs still active after 30 s return a job ID when push: true; a local box watch process delivers the finished output via t3 thread send.

07 · Pull artifacts & keep /cache

box_pull copies binaries, wheels, or APKs back to the laptop worktree within the 30 min throwaway window while /cache stays warm.
